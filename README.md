# redmonddispatch.com

Static landing site for the Redmond Dispatch newsletter (GitHub Pages). Generated by `site/dispatch/build.py redmond` in the RexMont ai-ops repo. Edit there, rebuild, push here. The signup form posts to the n8n webhook `redmond-dispatch-signup`, which creates the beehiiv subscription with custom fields; beehiiv → n8n → Follow Up Boss.
